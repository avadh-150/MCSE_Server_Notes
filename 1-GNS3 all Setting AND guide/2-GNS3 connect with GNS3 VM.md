After installing and running the GNS3 VM, you need to make the connection to your GNS3 simulator software.

Step 1

In the server configuration window that opens after clicking Help / Setup Wizard from the GNS3 tool menu, select the Run appliances in a virtual machine option so that you can run the network devices on the server and click Next.

![Run appliances in a virtual machine](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-11.webp)

---

Step 2

Configure the Host Binding IP address in the local server configuration as the IP address block of the GNS3 VM.

![Changing the Host Binding Address](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-12.webp)

---

Step 3

Continue after establishing a connection with the GNS3 server.

![Checking Server Status](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-13.webp)

---

Step 4

In the GNS3 VM window, select one of the VMware or VirtualBox virtualization programs from which you have imported the OVA file. If you have more than one virtual server, you can change it from the VM Name.

To make the virtual server work more efficiently, change the number of vCPUs to 2 and set a suitable RAM size according to the memory capacity of your host computer.

![Choosing VMware Virtualization Software](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-14.webp)

---

Step 5

After activating the GNS3 virtual machine, you will see that the server is started in the Servers Summary section. After checking the settings in the Summary window, close it.

![Checking the Server's Summary Information](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-15.webp)

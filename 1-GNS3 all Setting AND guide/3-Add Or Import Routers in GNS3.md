## How to Add Cisco Router IOS

After adding the GNS3 VM to GNS3, you need to add an IOS image of the Cisco Router or Switch devices on the server.

Step 1

Click File / Preferences from the GNS3 tool menu to add the IOS image.

![Opening GNS3 Preferences](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-16.webp)

---

Step 2

When you open the New IOS Router Template window, you need to select the server type to which you will add the IOS images. To run the routers on the GNS3 server, select the Run this IOS Router on the GNS3 VM option and click Next.

![Run this IOS router on the GNS3 VM](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-17.webp)

---

Step 3

Click Browse to add a Cisco IOS image you downloaded from our [article here](https://www.sysnettechsolutions.com/en/cisco-ios-download-for-gns3/).

![Choosing an IOS Router](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-18.webp)

---

Step 4

Select the c7200 IOS image and open it.

![Choosing Router IOS](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-19.webp)

---
Step 5

Click Yes to decompress iOS.

![Decompressing iOS](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-20.webp)

---

Step 6

Wait while the Router c7200 image is being uploaded to the GNS3 server.

![Uploading Router Image to Server](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-21.webp)

---

Step 7

You can change the name and platform of the Router you added or continue with the default values.

![Editing Name and Platform](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-22.webp)

---

Step 8

Configure a suitable memory size for the Router according to the performance of your host computer.

![Configuring the Router's Memory Size](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-23.webp)

---
Step 9

You can add FastEthernet, GigabitEthernet, or Serial Interface network adapters to the Router’s empty slots.

![Adding Serial Interface to Router](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-24.webp)

---
Step 10

Determine an appropriate Idle-PC value according to your computer not to use 100% of your host CPU and reduce its performance.

![Idle-PC Value Determination](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-25.webp)

---
Step 11

After checking the information on the IOS image you added to the Router template window, close the wizard.

![Closing the IOS Wizard](https://img.sysnettechsolutions.com/Linux-Mint-GNS3-VM-26.webp)
